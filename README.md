# SHG Analytics Pro Dashboard

## 📊 Overview

This project is a high-quality interactive dashboard built for analyzing Self Help Group (SHG) data under the National Rural Livelihoods Mission (NRLM).

It provides:

* Data visualization (charts, stats)
* Excel upload & processing
* PDF report generation
* Member-level analytics dashboard

---

## 🚀 Features

* 📁 Upload Excel files (.xlsx)
* 📊 Interactive charts using Chart.js
* 📄 Export reports as PDF
* 📈 Member-level insights
* 🌐 Clean 3D UI with Tailwind CSS

---

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS (CDN)
* Chart.js
* SheetJS (xlsx)
* jsPDF + AutoTable
* Leaflet (Map support)

---

## 📂 Project Structure

* `index.html` → Main dashboard (Hub)
* `Member_Dashboard.html` → Detailed member analytics view

---

## ▶️ How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
3. Upload your Excel file to start analysis
